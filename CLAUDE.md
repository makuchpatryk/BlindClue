# Claude Code Configuration

## Task Organization

Tasks should be managed in the `specs/` directory with the following structure:

- **`specs/todos/`** — Tasks that are in progress or planned
  - When creating a new task, add it here
  - File format: `task-name.md`

- **`specs/completed/`** — Finished, completed tasks
  - Move tasks here once they're done
  - Keeps a record of what's been accomplished

### Workflow
1. Create a new task → save to `specs/todos/`
2. Work on the task
3. Once complete → move to `specs/completed/`

This keeps active work organized and provides a clear history of completed items.
